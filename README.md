# qwe studio (English)

English version of the qwe studio website: websites, online stores, web and mobile apps, branding.

## Publish on GitHub Pages
1. Create a public repository named `design-studio-en`.
2. Upload everything from this folder so that `index.html` sits in the repository root.
3. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`, Save.
4. In 1-3 minutes the site is live at `https://qweqwasdd.github.io/design-studio-en/`.

If you pick another repository name, change `design-studio-en` in the `og:` and `canonical` tags at the top of `index.html`, otherwise the link preview will not load.

## What is inside
- `index.html` — the studio home page.
- `img/` — images for the portfolio and the link preview (`og.jpg`).
- `works/` — five live concepts (interface in Russian).
- `404.html` — page for unknown addresses.
